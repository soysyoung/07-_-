## 실행 전에
고정 조건: 분류 K=3, standard, p=2, 동일 분할
변경할 조건: weights를 uniform과 distance로 변경
예상 결과: valid F1 최대를 선택하고 동점이면 uniform을 우선한다.

## 실행 후
명령: python 06_특심화/main.py
실제 수치·출력 파일: uniform valid F1 0.545, distance 0.429, uniform 선택
검사 통과/실패와 수정 내용: 결측값을 train 중앙값으로 처리한 뒤 clone 독립성 확인

### 1. 고정 조건·후보 범위·주 지표·동점 규칙을 실행 전에 적어라.

작성: K=3·standard·p=2를 고정하고 weights 두 후보만 비교하며, 주 지표는 valid F1이고 동점은 uniform 우선이다.

### 2. 분류와 회귀에서 선택 K가 다른 이유는 무엇인가?

작성: 분류는 클래스 투표의 F1을 높이고 회귀는 숫자 오차 RMSE를 낮추므로 같은 K가 가장 좋을 필요가 없다.

### 3. train F1=1 또는 가장 큰 valid 점수가 최종 성능 보장은 아닌 이유는?

작성: train F1=1은 학습 자료를 외운 과적합일 수 있고, 작은 valid의 최고점은 다른 자료에서도 최고라는 보장이 없다.
