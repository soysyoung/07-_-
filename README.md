# 실습 저장소

수업 날짜와 예제 번호를 기준으로 실습 브랜치를 관리합니다.

## 브랜치 이름 규칙

```text
YYYYMMDD-exNN
```

예: `20261021-ex04`

## 실습 목록

| 날짜 | 예제 | 브랜치 |
| --- | --- | --- |
| 2026-10-21 | 실습 04 | [`20261021-ex04`](../../tree/20261021-ex04) |

각 브랜치로 이동하면 해당 날짜의 실습 파일을 확인할 수 있습니다.

## 커밋 규칙

커밋 메시지 작성 방법은 [COMMIT_CONVENTION.md](./COMMIT_CONVENTION.md)를 참고합니다.
